Installation en 3 étapes

Cinq minutes montre en main, clé API comprise.

  1. 1

    Télécharge et lance l'installateur

    Ouvre le fichier Url-AI Setup 1.3.0.exe. Si Windows affiche « Windows a protégé votre PC », clique sur Informations complémentaires puis Exécuter quand même.

  2. 2

    Installe, puis ouvre Url-AI

    Suis l'assistant (Suivant, puis Installer) : à la fin, le raccourci Url-AI apparaît sur ton bureau. C'est lui qu'il faut double-cliquer pour ouvrir l'application.

    ⚠️ Le fichier Url-AI Setup 1.3.0.exe que tu as téléchargé n'est pas l'application : c'est l'installateur. Le double-cliquer relance l'installation, ça n'ouvre pas Url-AI. L'application est le raccourci Url-AI du bureau, ou le fichier %LOCALAPPDATA%\Programs\Url-AI\Url-AI.exe.

  3. 3

    Colle une clé API

    Clique sur Paramètres (en bas à gauche), choisis ton fournisseur, colle ta clé et enregistre. Pour rester gratuit : Groq. Pour du hors ligne : Ollama.

Où trouver ta clé API ?

  • Groq (gratuit) : console.groq.com/keys
  • DeepSeek : platform.deepseek.com/api_keys crédits offerts à l'inscription
  • ChatGPT : platform.openai.com/api-keys payant à l'usage
  • Claude : console.anthropic.com payant à l'usage
  • Ollama : ollama.com/download local, gratuit, hors ligne

Questions fréquentes

Url-AI est-il vraiment gratuit ?

L'application l'est, totalement. Les modèles, eux, dépendent du fournisseur : Groq et Ollama sont gratuits, DeepSeek offre des crédits à l'inscription, ChatGPT et Claude sont facturés à l'usage par leurs éditeurs.

Windows affiche « Windows a protégé votre PC » à l'installation, c'est grave ?

Non. C'est l'avertissement habituel de Windows pour une application sans certificat de signature payant. Clique sur Informations complémentaires puis Exécuter quand même. Le code est entièrement local et lisible.

Au lancement, Windows dit « ffmpeg.dll est introuvable », comment réparer ?

Ce message signifie que le programme a été lancé sans les fichiers qui l'accompagnent. ffmpeg.dll doit toujours se trouver à côté de Url-AI.exe. Deux cas possibles :
1. Tu as lancé l'application seule (un Url-AI.exe isolé, sans le dossier complet) : retélécharge-la avec le bouton Télécharger pour Windows ci-dessus et lance le fichier Url-AI-Setup-…exe. Un Url-AI.exe seul ne peut pas démarrer.
2. Ton antivirus a mis ffmpeg.dll en quarantaine : c'est un faux positif connu. Sécurité Windows → Protection contre les virus et menaces → Historique de protection → cherche ffmpeg.dll → Actions → Autoriser sur l'appareil, puis réinstalle.

J'installe, je double-clique, et rien ne s'ouvre — ni fenêtre ni message

D'abord, vérifie sur quoi tu cliques : l'installateur (Url-AI-Setup-…exe) installe l'application, il ne la lance pas. C'est le raccourci Url-AI du bureau qu'il faut double-cliquer (ou %LOCALAPPDATA%\Programs\Url-AI\Url-AI.exe).
Ensuite, neuf fois sur dix, l'application tourne déjà en arrière-plan, même sans fenêtre visible : une seule instance à la fois est autorisée (la clé et l'historique vivent dans un seul fichier), et le second double-clic ne fait alors rien du tout. Ouvre le Gestionnaire des tâches (Ctrl + Maj + Échap), onglet Processus : si une ligne Url-AI apparaît, termine-la, puis relance depuis le raccourci du bureau.
Sinon, vérifie que le raccourci pointe bien sur %LOCALAPPDATA%\Programs\Url-AI\Url-AI.exe : s'il a été déplacé ou supprimé, réinstalle l'application. Le journal d'Url-AI, dans %APPDATA%\Url-AI\demarrage.log, dit toujours jusqu'où le lancement est allé et ce qui l'a arrêté.

Le fichier téléchargé ne pèse que quelques kilo-octets, c'est normal ?

Non, et ce n'est pas l'application. Un vrai installateur pèse environ 80 Mo. En dessous, c'est presque toujours la page d'erreur du serveur enregistrée sous le nom de l'installateur : le fichier porte la bonne extension, mais il ne contient pas de programme. Windows ne le lance pas et n'affiche aucun message.
Dans ce cas, préviens l'auteur du site : le fichier n'a pas été mis en ligne (un dépôt Git ne transporte pas les gros `.exe`). En attendant, la version portable ci-dessus fonctionne avec un seul fichier, sans installation.

Mes conversations et mes clés sont-elles envoyées quelque part ?

Non. Elles sont enregistrées uniquement sur ton ordinateur, dans %APPDATA%\Url-AI\. Le seul trafic sortant, ce sont tes messages envoyés au fournisseur que tu as choisi.

Il faut un PC puissant ?

Non, sauf pour Ollama : compter 8 Go de RAM pour un petit modèle local et 16 Go pour un modèle confortable. Les fournisseurs en ligne (DeepSeek, Groq, ChatGPT, Claude) ne consomment quasiment rien.

La version portable garde-t-elle mon historique ?

Oui : les deux versions partagent le même dossier de données, tu peux passer de l'une à l'autre sans rien perdre.
